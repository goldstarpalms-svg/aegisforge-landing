# Contributing

Thanks for helping improve AegisForge.

## Development workflow

1. Install dependencies with `npm install`.
2. Start the app with `npm run dev`.
3. Run `npm run validate` before opening a PR.
4. Keep components accessible, responsive, and performance-minded.

## Standards

- Prefer small, reusable components.
- Preserve the premium dark-first visual language.
- Maintain strong TypeScript types.
- Keep Lighthouse, SEO, and accessibility in mind for every change.
